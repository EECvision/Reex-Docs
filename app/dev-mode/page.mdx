# Dev Mode

Dev Mode is the flagship experience of Reex API Builder. It establishes a direct link between the Reex API Builder UI and your local React application.

In this mode, Reex API Builder acts as a companion app that lives alongside your development server. It installs necessary dependencies for API integration, and injects generated API code directly into your project.
