# Getting Started with API Sandbox

### Launching API Sandbox

API Sandbox is available directly in the Reex API Builder web app:

1. Visit [https://studio.reex-api.dev/](https://studio.reex-api.dev/)
2. Open the **workspace switcher dropdown** in the top navigation bar and select **API Sandbox**.

### Switching from Other Modes

If you are currently in Preview Mode or Dev Mode, open the **workspace switcher dropdown** in the top navigation bar and select **API Sandbox** to switch modes.

> **Auto-save enabled:** All your work in API Sandbox is automatically saved in real-time. You won't lose progress even if you close the browser.
