# API Sandbox

API Sandbox is built specifically for API developers who need a fast, flexible scratchpad for testing endpoints on the fly. Unlike Preview Mode where you import existing collections, API Sandbox lets you create and organize requests from scratch.

### What is API Sandbox?

API Sandbox is a lightweight, developer-focused environment for rapid API testing and experimentation. It's designed for situations where you need to quickly test an endpoint without the overhead of formal API specifications.

**Perfect for:**

- **Rapid Prototyping** - Test new endpoints as you build them
- **Quick Debugging** - Isolate and test specific API calls
- **Local API Testing**: Test APIs against a localhost server. To enable this, run the following command in your terminal:

```bash
  npx reex-proxy
```
