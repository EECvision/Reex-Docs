# Getting Started with Preview Mode

Reex API Builder defaults to Preview Mode when no project is connected. The app operates in one of three modes at any time: **Dev Mode**, **Preview Mode** or **API Sandbox**.

### Launching Preview Mode

Visit the web app directly to launch in Preview Mode:

[https://studio.reex-api.dev/](https://studio.reex-api.dev/)

No setup is required — the app is ready for you to import and test collections immediately.

### Switching from Dev Mode

If you are currently in Dev Mode, use the **workspace switcher dropdown** in the top navigation bar and select **Preview Mode**.
